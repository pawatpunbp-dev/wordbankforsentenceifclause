🧩 คลังคำศัพท์สร้างประโยค If-Clause

เลือกหมวด → เลือกชนิดของคำ → แตะคำเพื่อดูคำอ่าน คำแปล และฟังเสียง

💡 คำนาม ใช้เป็นประธานหรือกรรม • คำกริยา ต้องผันตาม Type (Type 1 ใช้ V1, Type 2 ใช้ V2, Type 3 ใช้ had + V3) • คุณศัพท์ ใช้หลัง be เช่น is / were / had been • กด ⭐ เก็บคำ เพื่อรวบรวมคำที่จะใช้ แล้ว แต่งประโยคเองในใบงาน
